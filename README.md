# Transformation-180

Персональное приложение для планирования и отслеживания физических тренировок.

## Основные задачи
- Планирование тренировок
- Учёт упражнений, подходов и повторений
- Отслеживание личного прогресса
- История тренировок
- Статистика и достижение целей

## Технологии
- GitHub — хранение кода
- Vercel — размещение приложения
- Supabase — база данных и авторизация

Статус: начальная разработка.
